# AI Agent Coordination

Use `AGENTS.md` as the only repository routing and architecture source of
truth. Use `docs/specs/README.md` as the SDD policy and document-role source of
truth.

## Entrypoints

- Copilot CLI: `.github/copilot-instructions.md`
- Codex role contracts: `.codex/agents/*.md`
- Codex invocation adapters: `.codex/skills/*/SKILL.md`
- Canonical reusable procedures: `.agents/skills/*/SKILL.md`

## Routing

Follow the deterministic SDD routing in `AGENTS.md`:

`feature-author` → `plan-author` → `plan-reviewer` → Human Approval →
`implementer` → `implementation-reviewer` → completion gate →
`feature-closer` → closure approval.

Findings return to the owning author or implementer. Scope, design, impact, or
approval-boundary changes return to planning. `$release-extension` uses its
canonical release procedure and is outside the seven SDD roles.

This file is an index only. Do not duplicate SDD policy, role authority,
model assignments, or procedure checklists here.
