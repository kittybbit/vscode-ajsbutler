## Slice 2 Replan Boundary

The replan trigger is the confirmed VSCE 3.9.2 behavior that includes
`README.en.md` but excludes `CONTRIBUTING.md`; the current plan's
`CONTRIBUTING.md` VSIX-inclusion prerequisite cannot continue unchanged. The
revised implementation plan accepts the `README.en.md` inclusion, keeps
`CONTRIBUTING.md` as a repository-only developer document, and changes the
contributor links in both `README.md` and `README.en.md` from relative
`CONTRIBUTING.md` targets to the canonical URL
`https://github.com/kittybbit/vscode-ajsbutler/blob/main/CONTRIBUTING.md`.
Relative README links inside `CONTRIBUTING.md` remain allowed, while links to
ignored internal documents remain canonical HTTPS repository URLs.

The new VSIX validation records the expected `vsce ls` result: `README.md`,
`README.en.md`, and the two existing images are included, while
`CONTRIBUTING.md`, `docs/`, `.agents/`, and `AGENTS.md` are excluded. Both
generated `extension/README.md` and `extension/README.en.md` must have no
broken relative `CONTRIBUTING.md` target and must contain the canonical URL;
all VSCE/package commands and the separate source-page previews must run only
from a disposable checkout/copy containing the three uncommitted
implementation files. The original implementation worktree's complete
`git status` and `git diff` must be byte-for-byte unchanged before and after
those checks; only the temporary VSIX and disposable checkout/copy may be
removed. `.vscodeignore`, package settings, images, runtime code, tests, and
generated artifacts are not changed by this replan.
